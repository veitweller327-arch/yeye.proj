TIMING SHIFT FX 1.1 - OpenFX-Effekt fuer DaVinci Resolve 20 Studio (Windows 10/11, 64 Bit)
=========================================================================================

INSTALLATION (einfachster Weg)
  1. DaVinci Resolve schliessen.
  2. "TimingShiftFX-1.1.0-Windows-Setup.exe" doppelklicken.
     - Windows SmartScreen meldet evtl. "Unbekannter Herausgeber" (die Datei ist
       nicht digital signiert): "Weitere Informationen" -> "Trotzdem ausfuehren".
     - Die Frage nach Administratorrechten mit "Ja" bestaetigen.
  3. Resolve starten.

ALTERNATIVE OHNE SETUP.EXE (ZIP-Paket)
  1. ZIP komplett entpacken (Rechtsklick -> "Alle extrahieren").
  2. "Install-TimingShiftFX.bat" doppelklicken, Administratorrechte bestaetigen.
  ODER von Hand: den Ordner "TimingShiftFX.ofx.bundle" nach
     C:\Program Files\Common Files\OFX\Plugins\
  kopieren (Ordner "OFX\Plugins" ggf. anlegen).

  Ergebnis muss so aussehen:
  C:\Program Files\Common Files\OFX\Plugins\TimingShiftFX.ofx.bundle\Contents\Win64\TimingShiftFX.ofx

EFFEKT BENUTZEN
  Edit-Seite:  Effects (oben links) -> Suchfeld "Timing" -> "Timing Shift FX"
               auf einen Clip in der Timeline ziehen -> Clip anklicken ->
               Inspector (oben rechts) -> Reiter "Effects".
  Color-Seite: Node auswaehlen -> Effects-Bibliothek (oben rechts) ->
               "Timing Shift FX" auf den Node ziehen -> Einstellungen im
               Settings-Bereich.

DEINSTALLATION
  Windows-Einstellungen -> Apps -> "Timing Shift FX (OpenFX plugin)" -> Deinstallieren
  (oder Uninstall-TimingShiftFX.bat aus dem ZIP-Paket).

EFFEKT ERSCHEINT NICHT?
  Siehe docs/04-Fehlerbehebung.md im Projekt. Kurz:
  - Resolve komplett neu starten.
  - Pfad oben pruefen (genau diese Ordnerstruktur!).
  - Resolve: DaVinci Resolve -> Preferences -> System -> Video Plugins: Ist
    "Timing Shift FX" aufgelistet und aktiviert?
